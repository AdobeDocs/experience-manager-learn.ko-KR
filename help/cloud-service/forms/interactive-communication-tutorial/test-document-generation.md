# API를 사용하여 IC 문서 생성

API 및 Postman을 사용하여 대화형 통신 문서를 생성하는 방법에 대해 알아봅니다. 이 프로세스에는 문서 ID를 가져오고, 요청을 인증하며, 사전 채우기 구성을 사용하여 PDF를 렌더링하는 작업이 포함됩니다. 동적 런타임 매개 변수 전달 및 보안 인증을 위해 이 API를 애플리케이션에 통합하는 방법을 알아봅니다.
