# 대화형 통신 템플릿 만들기

대화형 통신 템플릿을 만들어 발신 통신을 표준화하는 방법에 대해 알아봅니다. 이러한 템플릿은 고객 커뮤니케이션에서 일관성, 거버넌스 및 브랜드 정렬을 보장합니다. IC 웹 Designer 및 개체 라이브러리와 같은 도구를 사용하여 템플릿을 만들고 편집하고 향후 사용할 수 있도록 설정하는 프로세스에 대해 알아봅니다.
